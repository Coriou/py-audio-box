## Implemented boundary

QwenExecution is a closed detached descriptor with exact bundle/raw manifest digest/checkpoint/revision, voice identity/revision, task/language, explicit cpu/cuda:N/mps, dtype/attention, thread/memory/text/output/time bounds and optional typed conditioning. CPU defaults to float32/sdpa; no automatic device selection exists here. Best-compatible hardware selection remains the existing trusted profile owner's responsibility. CPU reduced precision, MPS bf16 and non-CUDA flash attention refuse. Seed refuses because this operator capability contract establishes no supported seeded execution semantics.

Trusted HardwareInventory must contain supported/available indexed device and probe provenance; native MPS additionally requires Darwin arm64/aarch64 native topology. Docker and unknown topology cannot authorize Metal. Runtime loader rechecks CUDA availability/index or actual Darwin arm64 MPS availability, forwards exact device/dtype/attention, and never calls automatic policy on explicit calls. Legacy callers retain automatic device/attention defaults and forwarding compatibility. Thread count is set before importing upstream Qwen loader. Memory is a declared reservation requirement, not Python-enforced containment.

Local verification precedes backend construction and Torch import: canonical no-follow owned paths, no group/world-writable leaf assets, complete raw-manifest hash, each listed asset's size/full streaming hash and stable metadata, bounded file counts/sizes, supported asset suffixes, required config/generation config/safetensors, no unlisted assets or symlinks. Sealed immutable managed storage throughout the attempt remains required; this is not isolation from same-UID concurrent writers. No acquisition path, remote checkpoint, public filesystem path or prompt/pickle input is accepted by execute.

Checkpoint mode/direction comes from existing checkpoint_capabilities/validate_checkpoint_request against the hashed local config. Only clone, custom_voice and voice_design are dispatched through named service methods. Clone verifies exact authorized voice/revision/model/revision/transcript mapping and bounded complete mono PCM16 reference bytes/hash/rate/frames. A private 0700 namespace receives a temporary WAV snapshot; existing model child constructs and consumes the clone prompt within that child. No executable conditioning is imported or exported by this interface. Preset/design invoke only their named upstream methods. Output model metadata must match local checkpoint/revision; measured sample rate must match capability, with finite real mono samples in [-1,1], finite frame/byte limits and PCM16 encoding. Close runs on all post-construction paths; close failure prevents a successful return.
