## Concrete blockers to the next real product slice

These are implementation gaps at the activation boundary, **not retrospective defects in the explicitly synthetic milestone**.

1. **Execution is hard-coded to silence.** Dispatcher passes `('silence', 8)`; Admission permits only `cpu-synthetic`, reserves fixed 192 MiB/2 MiB demand and limits output to 4,800 frames/9,644 bytes; `worker/runtime_child.py` imports the synthetic runner. Wiring a legacy backend factory alone cannot produce accepted real speech. Replace these restrictions with a closed, selected engine/profile execution descriptor and finite per-profile output/resource limits, retaining existing reservation and publication fences. Do not merely remove the checks or rename synthetic qualification receipts.
2. **Prepared reference and audition are conflated.** `service/production.py:23` assigns the reusable reference an audition ID; `worker/synthetic.py:18-33` uses the output for both; `contracts/validate.py:173-189` requires reference ID = audition ID and retains the submitted reference transcript. That works as a silence fixture. For real clone preparation it would either require treating cleaned reference audio as an “audition,” or save generated speech with a potentially wrong transcript and a second-generation voice reference. Separate the prepared reference from an explicit generated audition before Pocket/Qwen cloning. Preserve exact reference bytes/segment/provenance and transcript association. Design may intentionally reuse a generated reference, with its actual spoken text and design lineage; do not apply that rule to ordinary clone preparation.
3. **Legacy Qwen does not enforce a selected profile.** `lib/tts.py:478-499,664-711` chooses device through environment/auto detection, can silently fall back from requested CUDA to CPU, and chooses attention from installed availability. Its loader has no explicit device/attention arguments. A real service adapter must pass and verify exact device/index, precision, attention, local checkpoint and revision. Preserve legacy defaults for legacy callers. Never report a frozen CUDA/MPS identity while running a substituted CPU configuration.
4. **Provisioning and installed activation are incomplete.** `scripts/provision-tts.py` is useful existing acquisition/pinning code, but writes into an empty final destination, refuses a nonempty retry and does not supply resumable staging/atomic activation or Qwen bundle provisioning. `service/compose.release.yml` remains 0C/fake-worker; production commands explicitly refuse enrolled installations. Deliver a deliberate supported installation path and exact persistence/enrollment integration. Removing the `enrolled` guard without satisfying that boundary is not an installation implementation.
