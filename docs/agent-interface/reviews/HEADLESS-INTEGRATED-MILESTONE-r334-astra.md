3. **Finite native capacity and trust renewal are unresolved.** Separate registration/journal caps and retained byte quotas can exhaust independently of the history count. 4. **Installation is not yet the promised easy product journey.** Linux installation requires rootful local Linux and refuses Docker Desktop/rootless/remote layouts. That does not satisfy constrained Intel Mac installation. Native launch binds host loopback without establishing Docker reachability, exact mounts/firewall/peer isolation, or a compatible arm64 wheelhouse/ABI. NATIVE-PACKAGE still contains earlier “no clean clone journey” prose; consolidate current operator instructions with the installed deliverable. Repeated package-only checks will not close these gaps.
5. **Stronger-hardware usability remains unmeasured.** Selection checks capacity but introduces no concurrent runtime scheduler.
