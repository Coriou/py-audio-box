## Changes

R1: every existing/new bundle is checked and sealed before active pointer replacement. Files are single-link owned regular files; file data is fsynced, files chmod 0444, directory chmod 0555, and writable mode bits are checked. A failed final directory chmod cannot be bypassed on retry: existing bundles reverify exact bytes/manifest and repeat sealing. Staging directory stays private/writable until rename; partially sealed files are reused if pins match, while the old manifest is unlinked before exclusive fresh content creation, so recovery does not write through a read-only or hardlinked inode. No asset redownload is required merely because sealing failed.

R2: managed acquisition passes each expected size to the real downloader. It requests at most remaining expected bytes plus one overflow byte, refuses overflow before writing it and refuses short EOF. At most expected bytes reach disk per asset. A disposable POSIX fork child owns blocking URL open/read/fsync; parent imposes a default 300-second whole-transfer deadline, polls trusted cancellation at up to 50-ms intervals, terminates, allows 200 ms, then kills/reaps before returning. Socket timeout (10 seconds) is supplementary. Default lock wait is 30 seconds, uses nonblocking flock with monotonic deadline/cancellation, and its descriptor is inside finally even when acquisition fails. Positive finite budgets are required. Budgets are per asset transfer and lock wait, not a deadline over local hashing/sealing or an OS scheduling/disk-uninterruptibility guarantee. Confirmation of child reap is retained before returning and releasing the lock.

Injected downloader callbacks retain the two-argument trusted seam and are explicitly responsible for their own bounds; malicious Python callbacks are not contained or claimed bounded. The managed real downloader is exercised with inert URL sources, including an indefinitely stalled open in its actual child. Legacy two-argument download retains EOF semantics, with finite 4-GiB cap and transfer deadline; Pocket acquisition code and manifest schema are otherwise unchanged. No real upstream journey was run.

Directly related storage admission creates root/staging/bundles directories mode 0700 and refuses existing nonprivate or foreign-owned directories. Lock paths refuse FIFO/symlink/nonregular/multilink/foreign-owned/nonprivate entries; O_NONBLOCK avoids FIFO-open blocking and fstat checks the opened descriptor. All managed staged/bundle files and existing pointer/temporary files refuse nonregular, symlink, foreign-owned or hardlinked entries before mutation. The root's ancestors must remain canonical and nonsymlinked. These checks assume private operator storage with no hostile concurrent filesystem mutation; they are not a dirfd/race-hardening framework.
