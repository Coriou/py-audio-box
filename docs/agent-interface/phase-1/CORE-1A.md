## Implemented boundary

`service.domain.DurableCore` exports the sole new store/domain implementation from `service.core.Core`. The retained `read` function continues to serve explicitly synthetic 0C fixture reads. No new HTTP route, CLI command, MCP tool, readiness claim or studio integration is exposed. Core methods are trusted control calls, not externally authorized operations. Authentication/authorization and error transport mapping belong to 1B after core completion.

Versioned SQLite migration 1 uses WAL/FULL synchronization, foreign keys, two-second busy handling and short immediate transactions. One advisory control lock excludes a second writer in the same private root. Immutable project snapshots retain exact text and history; `edit_text` uses transactional CAS and existing edit semantics, preserving clips, takes, assets and historical versions. It starts no work. `project(id, revision)` exposes history without deleting revisions.

`submit_synthetic(principal, key, context)` accepts a trusted canonical frozen context, validates the existing oracle relations and stores it serialized separately from caller objects. Duplicate lookup is principal/operation/key scoped and occurs before revalidation/resolution: the same request returns its existing job; a changed canonical request conflicts. Input hash is the existing full `plan_hash`, separate from request fingerprint. Explicit terminal retry creates a new job with durable `retry_of` lineage and requires identical context/principal. There are no automatic retries or replacement generations. Jobs/events use persisted sequence cursors with at most 20 results per call.

Execution supports **one synthetic preset speech variant, reuse=never, no input assets**. Render, clone, prepare, design, additional variants and exact reuse explicitly raise `NotImplementedError`; they are not silently approximated. Synthetic execution deliberately bypasses real profile readiness admission and must never be wired as real synthesis. Fixture Qwen identity is a canonical relational input only; the worker generates 4800 frames of PCM16 silence, not Qwen output. Real profile discovery stays unqualified/not-ready.

One lane per control root runs a real one-shot worker process via a private inherited Unix socket pair. Control creates a parent-owned `0700` attempt directory and an inherited owner lock before spawn. Tuple/plan/deadline/result relations are checked by the existing oracle against persisted authority and the child-bound socket, never a JSON owner claim. Stop waits/reaps the child before terminal cancellation. A complete verified result may win `cancel_requested`. Deadline expiry kills and waits, then fails. A Linux connection reset after confirmed reap is an absent result, not a cancellation failure.

Control opens staged media without following the final symlink, checks private stage mode/owner and file owner/type/link count/size, hashes bytes, decodes WAV, checks complete frames and fixed synthetic output policy/provenance, then calls canonical publication validation. A worker manifest is only a proposal. A durable intent precedes same-filesystem atomic no-replace adoption (private temporary bytes, file fsync, hard link, unlink temporary, directory fsync); DB asset/artifact references and success commit together only after rechecking adopted hashes. Asset/artifact lookup uses stored managed IDs and checks files, never caller paths.

Restart obtains the control lock and examines inherited owner locks. A live owner quarantines the lane: no kill, replacement, cleanup or retry. Once the kernel releases the known fake owner's lock, a complete adopted intent can commit; absent/partial adopted media causes an explicit interrupted failure. Before-adoption failure retains staged bytes; after-adoption/precommit recovery commits the one artifact; after-commit recovery leaves success unchanged. Orphan files and stages are retained, not blindly deleted. This fake worker does not spawn descendants; inherited-lock death evidence is not qualification of arbitrary real worker process trees or native companions.
