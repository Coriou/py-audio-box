# 0C boundary probe

This process answers only `0C-PING` over a private Unix socket. It executes no
canonical worker message and produces no audio. `contracts` worker protocol
1.3.0 remains authoritative for 1A; no schema is introduced here.

CPU and CUDA are future networkless container profiles. Metal is a separate,
optional packaged native companion with authenticated scoped local transport,
explicit managed-byte transfer and host-native staging. It will not receive
Linux paths or the database. Absence/disconnect must mean not-ready, with no
silent fallback. No CPU/CUDA/Metal ML profile is qualified by this probe.
